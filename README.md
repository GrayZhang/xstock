# X Stock Radar

X Stock Radar 是一个面向美股投资研究的 X 舆情与股票热点雷达。它把 X 上分散的市场讨论、股票代码、主题趋势和单股追踪信息整理成可浏览的信号面板，帮助更早发现正在升温但尚未完全进入大众视野的股票线索。

> 访问地址：[https://xstock.tejarvis.info/](https://xstock.tejarvis.info/)

## 这个仓库的用途

本仓库目前只作为项目介绍和访问入口，不存放线上系统源码、不同步部署脚本，也不包含任何 API Key、数据库、抓取数据或用户信息。

## 核心能力

- 市场雷达：追踪 X 上美股相关讨论，按热度、升温速度、作者扩散、主题和价格表现聚合。
- 早期机会筛选：优先关注有基本面或事件支撑、但还未完全被大众视野覆盖的标的。
- 单账号追踪：跟踪特定高质量 X 账号的股票提及、首次提及、内容分类和提及后的价格表现。
- 事件研究：登录后查看历史信号的事后表现、跑赢率和超额收益拆解。
- 主题分类：覆盖 AI 软件、AI 算力云、机器人和物理 AI、量子计算、光通信光子学、能源资源等方向。
- 账号体系：登录后进入完整 Pro 视图，未登录状态仅展示预览内容。

## 适合用来做什么

这个工具适合用来辅助观察：

- 哪些股票正在被更多账号讨论
- 哪些主题正在升温
- 哪些股票是某个账号近期首次提及
- 一只股票被提及后，价格是否已经反应
- X 上的讨论是否只是情绪噪音，还是有持续扩散和事件支撑
